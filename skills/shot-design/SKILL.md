# 镜头设计

给 `chapters/<章节号>/shot-split.md` 里每个事件贴镜头标签，输出 `chapters/<章节号>/shots.md`。
本步只填镜头级字段，**不填连续性字段**（角色 position、道具、首帧提示词）——那些归下游 skill。

## 范围边界

- 做：读 shot-split.md → 给每个事件填 职责/时长/景别/机位/声音/动作 → 写 shots.md
- 不做：角色 position、道具、首帧提示词、CLI 编译——这些归下游 skill

## Quick Start

无需 CLI。本 skill 纯文本处理，只用 read/write/edit。

## 入口

- 已执行 shot-split：读取 `chapters/<章节号>/shot-split.md`，每个 `### E<编号>` 是一个镜头候选。
- shot-split.md 不存在时提示用户先跑 shot-split。

## 工作流

1. **准备**：读 `chapters/<章节号>/shot-split.md`。列出场景清单（SC 编号、地点、事件数），不展开。
2. **逐场景填字段**：对每个场景的每个事件，填以下字段。每填完一个场景，立即把该场景的镜头块追加写入 `shots.md`，再填下一场景。**禁止把整章攒到最后一次性写入**——逐场景落盘后中断只丢正在写的那个场景。
3. **自查**：每个事件都有镜头块；镜头编号在场景内从 1 起递增，连续无跳号。
4. **完成**：列出全章镜头总数请用户确认。

## 字段填写规则

### 镜头编号

`SHOT-<场序>-<镜序>`，场序对应 SC 编号，镜序场景内从 1 起递增。一个事件 = 一个镜头，不拆不并。

### 职责

本镜结束时观众或人物发生了什么变化：建立空间、展示证据、转移权力、表现反应、让后果无法回避。
「中景展示人物说话」不是职责。

打击、否定、翻盘需要观众理解后果时，必须有可读的反应承载：独立反应镜、双人镜内调度、清楚的群像反应、声音或物件状态。现有画面已清楚时不补镜——按「后果能否被读出」判断，不按反应镜数量。

### 时长

5/10/15 三选一，基于「表演」字段估时——表演融合了动作和对白的时序，按整段表演的实际耗时估时，不是分开算再加。

- 对白字数 ÷ 4.5 = 对白秒数（只算汉字和数字，不算标点）
- 动作时间：打斗类约 4 秒，表情变化 1 秒，单个肢体动作 1 秒，复杂肢体动作 2-3 秒
- **同时发生的动作和对白只算一次时间**（如「一拍大腿说"我可以确定"」按对白秒数算，拍腿与说话并行不另加）
- 先后发生的动作和对白时间相加
- 加句间停顿（每处约 0.3 秒）和说完后的反应
- 取容得下的最小合法档；不要先选短档再让人物加快语速
- 超过 15 秒容量 → 该事件需拆成两个镜头，回到 shot-split 重新拆分该事件
- 纯动作镜（无对白）按动作时间选档，内容不足选短档，不为凑满时长注水

### 景别

按人数和动作幅度判断：

| 人数 | 动作幅度 | 景别 |
|---|---|---|
| 1 人 | 小（表情/细微动作） | 近景或特写 |
| 1 人 | 大（起身/转身/挥手） | 中景 |
| 2-3 人 | 互动 | 中景 |
| 4 人以上 | 群像 | 全景或中景（靠纵深分层） |

- 景别只在注意或关系变化时改变；不把景别当情绪音量旋钮
- 关键信息的可读性优先于装饰性运镜
- 竖屏以中景、近景、特写为主；远景/全景要靠纵深分层（前景遮挡、门框、台阶、人物前后）承担交代空间的职责，做不到就改更近的镜头单独给一次；竖屏构图优先保证主体和反应可见

### 机位

`<角度>·<运镜>` 格式，如 `平视·固定`、`俯视·缓慢平移`。
- 角度：平视 / 俯视 / 仰视
- 运镜：固定 / 缓慢平移 / 缓慢推近 / 缓慢拉远；单词默认运镜为固定
- 单个场景中尽量保持镜头固定，减少运镜

### 声音

只写对白，不加背景音、配乐、音效。
- 从 shot-split.md 事件段落里提取台词，写成 `角色（语气/表情）：台词` 格式
- 括号里写语气、情绪或表情（如「压低声音」「冷笑」「轻声」「皱眉」），不写策略、不写抽象内心状态；括号里的肢体动作（如「一拍大腿」「连连点头」）不照搬，移到「动作」字段
- 无语气修饰时省略括号，直接写 `角色：台词`
- 无对白时留空

### 动作

从 shot-split.md 事件段落里提取括号舞台指示（动作、表情、环境变化），以及声音字段括号里剥离出来的肢体动作，去掉括号，按发生顺序写成自然段。
- 动作的本质是凸显职责——只写承载本镜职责的关键动作，不堆砌过程细节
- 一个分镜中不超过 2 个动作；动作简单明显，视频模型能直接生成
- **人数多的场景以及远景人物动作要更简单，甚至没有动作**：多人同框时模型难以协调复杂动作，群像镜优先只给站位和朝向
- 用主动语态写清施动者，禁止被动句（"A 被人捂嘴" → "B 捂住 A 的嘴"）
- 动作写常见动作的组合与时机；精细编排（运动中截物、三步以上双手动作）图生视频不可用
- 只写视觉动作，不写声音描述（如「吵闹声渐远」不进动作字段）
- **表情从固定词表选**：视频模型只能生成有限的大表情，写表情时从下表选一个可见表达，不要自造描述（「目光躲闪」「嘴角微翘」「眼神复杂」这类微表情模型生成不了，必须换成词表里的可见表达）

  | 情绪 | 可见表达 |
  |------|----------|
  | 喜/乐 | 笑、咧嘴笑、大笑 |
  | 怒 | 皱眉、瞪眼、咬牙 |
  | 伤心 | 低头、垂眼、哭 |
  | 惊 | 瞪大眼、张嘴 |
  | 慌 | 四下张望、缩身、后退 |
  | 恐惧 | 后退、僵住、脸色发白 |
  | 思考 | 皱眉、低头、托腮 |

  微表情转译示例：「嘴角慢慢翘起」→「咧嘴笑」；「目光躲闪」→「别开脸」；「神色没起波澜」→ 删掉或转成对白。转译后删掉原微表情，只留词表里的表达
- 无动作则不写

### 表演

把「声音」和「动作」两个字段的内容按发生顺序融合成一段叙述，体现真实的时间关系。视频模型按这段叙述安排画面和声音的时序。

根据本镜的职责、语境和场景，判断动作与对白怎样编排最合理最通顺——不是机械拼接，而是让表演服务于职责。

**时序关系写法：**
- **同时发生**：动作和对白写在同一句，用「一边...一边...」或直接并列。例：`董问君一拍大腿说"我可以确定，这就是小师弟，没错了！"`
- **先后发生**：用「然后」「接着」连接。例：`陈青源冲众人一摊手，然后说"那个啥，我有点儿累了，先回去休息了"`
- **对白中间插入动作**：用「然后...继续说」标明插入点。例：`陈青源说"那个啥"，摊手，然后继续说"我有点儿累了，先回去休息了"`
- **纯动作镜**：只写动作，无对白。例：`众师兄一拥而上捂住陈青源的嘴`
- **纯对白镜**：只写对白，无动作。例：`董问君说"什么都没查出来……可死了百年的人突然活着回来，莫不是被哪位大能夺舍了？"`

## 输出格式

`chapters/<章节号>/shots.md`：

```markdown
# 分镜 — ch<章节号>

## SHOT-1-1

- 职责：建立夺舍疑云，让陈青源从被动挨查转为准备反击
- 时长：10
- 景别：中景
- 机位：平视·固定

### 声音
董问君（压低声音）：什么都没查出来……可死了百年的人突然活着回来，莫不是被哪位大能夺舍了？

### 动作
陈青源目光从众人脸上一一扫过，落到董问君身上，咧嘴一笑。

### 表演
董问君压低声音说"什么都没查出来……可死了百年的人突然活着回来，莫不是被哪位大能夺舍了？"，然后陈青源目光从众人脸上一一扫过，落到董问君身上，咧嘴一笑。

## SHOT-1-2

- 职责：陈青源锁定董问君，用旧事启动反击
- 时长：10
- 景别：近景
- 机位：平视·固定

### 声音
...

### 动作
...

### 表演
...
```

## 修订

只改用户点名的镜头；未点名镜头保留不动。改完重写该镜头块即可。

## 完成

每个事件都有镜头块、字段完整、编号连续无跳号，即完成。下游连续性 skill 从 shots.md 起步，填角色 position、道具、首帧提示词。
