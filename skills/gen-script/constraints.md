# 剧本约束规则

本文件是剧本生成和审查的单一数据源。script-writer subagent 生成时遵守，script-reviewer subagent 审查时对照，主 agent 合并时参考。

发现矛盾一律对照 `novel.md` 原文核实，以原文为准。

## 1. 场景时长

每个场景 15 秒（约 40-60 字对白，只计角色台词，不含场景描写）。

- 太长（>60 字）：拆分为两个场景，或精简对白
- 太短（<40 字）：合并到相邻场景，或补充动作描写/对白

## 2. 场景完整度

- 内容截断：只有一两句对白 + 场景描写、没有完整情节 → 合并到相邻场景或补充内容
- 动作拆分：一个完整动作或对白被拆到两个场景 → 合并
- 空场景：只有场景描写没有对白和动作 → 合并或补充

## 3. 逻辑矛盾

逐个场景与小说原文对比：
- 角色出场：剧本是否凭空增加了原文不在场的角色
- 事实设定：剧本中的关键设定是否与原文一致
- 角色称呼：同一场景中对同一角色的称呼是否统一，是否符合原文关系
- 人物位置：角色位置转换是否合理，原文是否有对应交代

## 4. 场景切换

与原文的叙事节奏对比，场景不能生硬跳转：
- 遗漏转场：原文中有时间/地点跨度的地方，剧本是否跳过了
- 情绪衔接：原文中情绪转折的地方，剧本是否有对应过渡
- 角色动机：角色去下一个场景的原因，原文是否有交代，剧本是否保留

## 5. 格式规范

- **禁止使用旁白**：不允许出现画外音/旁白形式的叙述。背景信息只能通过「角色自述」（角色自己开口说）或融入对白、动作来交代。
- 角色自述格式：`角色名（自述）：内容`，表示角色自己开口交代背景，不是第三人称画外音。
