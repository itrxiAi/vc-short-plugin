# 首帧审查

对 `chapters/<章节号>/shots/shot_*/` 逐镜核对 `keyframe.png` 与 `shot.yaml` 中的 `performance`、`keyframe_prompt`、`characters`，输出结构化问题清单。

**只读技能**：不改 shot.yaml、不改 shots.md、不重新生成任何媒体。发现问题只写清"哪镜、什么问题、建议怎么改"，由用户决定是否修。

## 范围边界

- 做：读 shot.yaml + keyframe.png + assets 目录 → 逐镜检查 → 输出问题清单和修订建议
- 不做：修改源文件、重新生成首帧/视频、审查视频内容（视频问题另审）

## 工作流

1. **收集镜头清单**：`chapters/<章节号>/shots/shot_*/` 按分镜号排序。
2. **逐镜读文本**：从 shot.yaml 提取 `purpose`、`performance`、`keyframe_prompt`、`keyframe_source`、`characters`（含 position）、`scene`、`props`、`camera`。
3. **核对资产**：`characters` 里每个角色必须在 `assets/characters/` 有图（群演解析到 `assets/characters/群演/`：`群演-<格图名>#<格号>` = 格图某格，`群演N` = 平铺 `群演N.png`）。**无资产的角色 = 形象不可控**，必须记录。
4. **逐镜看图**：`keyframe.png` 缺失本身就是问题（视频只能靠尾帧/纯文本）。图片一次读 1～2 张，避免张冠李戴。
5. **按清单检查**（见下）。
6. **输出报告**：分严重级列出全部问题，末尾给修订优先级。

## 检查清单

### A. 人物错误

- **人数**：图中人数与 `characters` 数不符 → 指出多出的（复制分身 / 描述外角色乱入）或缺少的是谁
- **身份**：对照 `assets/characters/<名>/<名>.png` 核对五官、发型、服色；同一场景跨镜形象是否漂移
- **无资产角色**：`characters` 中有名但无图的 → 形象每次随机，重点标注
- **群演**：群演的性别、人数是否符合语境

### B. 首帧与描述不一致

- `keyframe_prompt` 写的**站位/姿态/持物/道具/景别**逐项对照图：写"站"图里坐、写"持杯"手里空、写了道具图里没有，都算不一致
- **上一镜承接**：有 `keyframe_source` 标记时，本镜起点应与上一镜 `action`/`performance` 的结束态一致（姿态跳变是高频问题）
- **画面文字**：牌匾、衣纹、卷轴上的文字是否可辨认且与设定一致；有无平台水印

### C. 可扩展性 / 构图合理性

- **动作所需空间元素是否在画面**：`action`/`performance` 中的走位目标、注视对象、关键道具必须在首帧可见或有合理入画路径
- **说话人归属**：`performance` 里有台词的角色必须在 `characters`（画面内）或已标注画外音——未标注的画外说话人会被视频模型物化进画面
- **构图重复**：与同场景上一镜构图完全相同的 → 切镜意义存疑，提示 `camera.angle` 应带具体机位（过肩/反打等）
- **遮挡风险**：`camera.movement` 的运动终点会不会被前景元素挡住主体

### D. 姿态与面部朝向

- **对话双方是否互相面对**：有对白的人应面向说话对象；朝向与台词对象不一致的不合理
- **发言者视线**：说话时脸应朝向听者；背对镜头者不应有需要表情反应的台词
- **姿态与职责匹配**：`purpose` 要求的关系（威慑/臣服/对峙等）应能从站位高低、距离、朝向读出
- **持物与肢体**：`position` 写了持物的，手部姿态要自然可信（穿模、浮空、手指数异常）


### E. 修复方案
- **减少内容**：在逻辑通顺的前提下，通过降低动作和提示词复杂度来进行修复

## 输出格式

按严重级分组，每镜一行：

```
## 审查报告 — ch<章节号>（共 N 镜）

### 必修（会直接导致错镜或穿帮）
- <镜号>: <问题描述 + 依据>

### 建议修
- <镜号>: <问题描述>

### 提示（可接受）
- <镜号>: <问题描述>

### 修订优先级
1. ...  2. ...
```

## 完成

逐镜无遗漏、每镜按四类清单判过、按严重级分组、给出修订优先级，即完成。审查不代替用户决定修不修。
