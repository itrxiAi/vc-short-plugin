# 填连续性

给 `chapters/<章节号>/shots.md` 里每个镜头块填连续性字段，原地修改 shots.md。
本步只填连续性字段，**不改镜头切分、不改职责/时长/景别/机位/声音/动作/表演**。

## 范围边界

- 做：读取 shots.md 和资产映射 → 一次性解析名称对应关系 → 逐镜头填 场景/角色/道具/首帧提示词 → 原地改 shots.md
- 不做：镜头切分、职责/时长/景别/机位/声音/动作/表演、CLI 编译——这些归其他 skill

## Quick Start

无需 CLI。本 skill 纯文本处理，只用 read/write/edit。

## 入口

- 已执行 shot-design：读取 `chapters/<章节号>/shots.md`，每个 `## SHOT-XXX-XX` 块已有 职责/时长/景别/机位/声音/动作/表演。
- 同时读取已有的 `character_map.yaml`、`scene_map.yaml`、`prop_map.yaml`；只在准备阶段读取一次。
- shots.md 不存在或字段不全时提示用户先跑 shot-design。

约束规则（动作唯一落实、边界连续等）见 `constraints.md`。

## 名称映射

在逐镜头处理前，先从 shots.md 收集角色、场景、道具名称并去重，统一解析一次：

1. 完全匹配已有 map；
2. 去除空格、括号、标点等格式差异后匹配；
3. 使用 map 中已有别名或唯一候选；
4. 存在多个候选时暂停并请用户确认，不自行猜测。

确认后的名称关系在本轮处理中复用，不对每个镜头重复匹配。写回 shots.md 时保留剧本标准名称；assets 目录名由下游 gen-shots 根据 map 映射。

## 填哪些字段

每个镜头块填 4 个字段：

1. **场景** — 镜头发生在哪
2. **角色** — 谁在场、站哪、持什么（position + 持物合一）
3. **道具** — 不属于任何角色的独立道具（无则不写）
4. **首帧提示词** — 起点可见画面

不单独填“终点”。本镜结束态由本镜的 `### 动作` 和 `### 表演` 推断；同一场景、同一连续动作链中的下一镜，角色站位、持物和首帧必须承接上一镜的结束态。

## 填写规则

### 场景

写剧本中的场景名称；名称偏差在准备阶段按 scene_map.yaml 统一解析，写回时保留剧本标准名称。

### 角色

格式：`角色名@位置/持道具, 角色名@位置`

- **position 只写静态**：站位、朝向、持物，不写动作（拍腿/起身/前倾归 `### 动作`）
- **持物写进 position**：`陈青源@大殿中央/持玉镯`；无持物不写 `/持...`
- **禁止群体称呼**：如果出现"众人/师兄们/师姐们/人群"等群体词，用场景中出现的具体角色和群演代替，人数为2-3人，具体角色优先
- **群演必须编号**：优先使用动作或表演中已经点名的群演；没有具体指代时按出现顺序使用`群演1@右侧坐席, 群演2@右侧坐席`，不随机更换编号
- **同步替换动作和首帧里的群体称呼**：填完角色字段后，检查 `### 动作`、`### 表演`、`### 首帧提示词` 里的群体词（众人/师兄们/师姐们/人群或类似词），替换为角色字段里对应的具体几位角色名或群演编号，确保三个字段的角色名一致
- **同一场景、同一连续动作链中的镜头**：position 从上一镜的动作结束态接续，不凭空重写
- **新主号或发生地点/时间切换**：按剧本重新设定 position
- 主要角色增减（离开/加入）需有画面依据——上一镜的动作结束态或本镜的动作段能解释该角色为何在场或不在场；背景群演增减无需交代

### 道具

只写**不属于任何角色的独立道具**（帝王剑剑腾空而起）。

- 格式：`道具名@状态`，如 `帝王剑@腾空`
- 角色持有的道具写进角色的 position，不在这里重复
- 无独立道具则不写此字段
- 跨镜出现的独立道具必须列出，状态变化（易主、拆封、损坏）在 `@状态` 写明本镜开始时的状态

### 首帧提示词

只写本镜起点画面里能看见的内容：站位、持物、环境。

- **终点才出现的内容必须删掉**：动作完成态、过程中才露出的文字、转手后才改变的持物
- 判断方法：把 `### 动作` 段里的动作动词遮掉，首帧里就不该出现那个动词带来的状态
- 首帧点名的人物、道具必须与本镜角色和动作段一致
- **同主号连续镜头**：首帧提示词必须与上一镜的动作结束态一致（gen-video 用上一镜尾图作起始画面）
- **新主号第一镜**：首帧提示词是唯一起点来源，必须写全构图、站位、持物
- **不写人物外貌、五官、服饰等形象描述**：只写起点可见的站位、朝向、持物、环境和动作状态；人物形象通过参考图控制

## 工作流

1. **准备**：读取 shots.md 和三个 map 文件，识别镜头顺序、场景切换位置，并一次性完成去重后的名称解析；不单独输出镜头清单。
2. **逐场景填字段**：按镜头顺序填场景/角色/道具/首帧提示词。完成一个场景后统一写回 shots.md；场景过长时每 5～10 个镜头写回一次。
3. **场景内检查**：检查字段完整，以及同一连续动作链中的角色、持物和首帧承接；发生地点、时间或主号切换时重新建立起点。
4. **完成**：列出全章镜头总数请用户确认。

## 输出格式

每个镜头块在 `### 声音` 之前插入字段，`### 首帧提示词` 放在 `### 表演` 之后：

```markdown
## SHOT-1-1

- 职责：...（已有，不改）
- 时长：10（已有，不改）
- 景别：中景（已有，不改）
- 机位：平视·固定（已有，不改）
- 场景：玄青宗议事殿
- 角色：陈青源@大殿中央, 董问君@主位侧前方
- 道具：玉镯@陈青源怀中

### 声音
...（已有，不改）

### 动作
...（已有，不改）

### 表演
...（已有，不改；只同步群体称呼替换）

### 首帧提示词
玄青宗议事殿，淡白长袍青年陈青源站大殿中央，董问君坐主位侧前方
```

## 修订

只改用户点名的镜头；未点名镜头保留不动。

## 完成

每个镜头的连续性字段完整、动作唯一落实、首帧投影正确、边界连续，即完成。下游编译 skill 从 shots.md 起步，跑 CLI 生成 shot YAML。
