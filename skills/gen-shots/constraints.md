# 分镜约束规则

本文件是分镜生成和完成前自查的单一数据源。主 agent 生成时遵守，自查时对照。

发现矛盾一律对照 `novel.md` 原文核实，以原文为准。

## 0. 规则分级

| 级别 | 执行方式 |
|------|----------|
| **硬规则** | 违反必须修，审查可阻断：原文覆盖、编号规则、字段完整 |
| **镜头规则** | 审查必须引用分镜证据指出，不能凭感觉：镜头职责、动作唯一落实、首帧投影、边界连续、对白估时、承受者反应 |
| **默认手艺** | 通常有效，有明确戏剧理由可覆盖：一镜一个主要动作、竖屏景别习惯 |
| **题材选择** | 不作为问题指出：装饰性运镜偏好、风格化调度 |

## 1. 原文覆盖（硬规则）

- 剧本每个场景的每段制作相关内容（动作、对白、`[画面文字]`、`[转场]`）都必须由某个分镜承载
- 决定不拍的场次，必须在 `shots.md` 开头写 `- 未拍场次：<场景 ID>（理由：……）`；漏拍和有意省略在成稿里长得一样，区别只在理由写没写
- `[连续性]` 行不进分镜，但其状态要体现在相关分镜的 `角色` position、`终点` 和 `### 首帧提示词` 中
- **场景覆盖由 CLI 机械核对**（编译时执行）：场景缺失、未拍缺理由、既承载又未拍，任一命中编译失败；核对报缺失时只补写缺失场景的镜头，不重写已有镜头

## 2. 镜头职责（镜头规则）

- 每镜 `purpose` 写清本镜结束时观众或人物发生了什么变化：建立空间、展示证据、转移权力、表现反应、让后果无法回避
- 「中景展示人物说话」不是职责
- 切镜必须带来信息、权力、情绪、空间或节奏变化；**相邻两镜同景别、同角度、同人物关系 → 并回一镜**
- 同一动作不跨镜重复发生；不为换角度而重复同一个动作

## 3. 动作唯一落实（镜头规则）

- 转手、开门、受伤、亮出证物、揭面等动作，全章只有一个主要落实镜——只有它把状态从动作前改成动作后
- 其他分镜再次涉及该动作时，只能承担反应、细节或新信息，不能重新表演一遍
- 前一镜终点已是动作后状态时，后一镜不得再完整表演该动作
- 状态链 `起点 → 唯一主要动作 → 终点` 中，涉及交接、换手、放置时，接触者、接触方式和物件落点写在同一条链里，不能靠镜外瞬移衔接

## 4. 首帧投影（镜头规则）

- `keyframe_prompt` 只写本镜起点画面里能看见的内容：站位、持物、环境、光线
- **终点才出现的内容必须删掉**：动作完成态、过程中才露出的文字、转手后才改变的持物
- 首帧点名的人物、道具必须与本镜 characters 和剧本段一致，不能写画面里没有的东西
- **首帧来源判断**：gen-video 自动判断——同主号连续镜头用上一镜尾图作起始画面，新主号第一镜才按 `keyframe_prompt` 新建首帧图；因此本镜 `首帧提示词` 必须与上一镜 `终点` 一致，两条来源（尾图 / 新建首帧）才能得到同一起点

**正反例（"唯一动作"里发生的事不能提前进首帧）：**

| 唯一动作 | ❌ 错误首帧（混入过程/终点） | ✅ 正确首帧（只投影起点） |
|------|------|------|
| 林长生走到近前，伸手替陈青源整衣襟 | 林长生站在陈青源身前，手抬至衣襟处 | 林长生站在门口，陈青源站石床边 |
| 两人在桌边坐下 | 陈青源与林长生在桌边对坐 | 陈青源与林长生在石床边站着 |
| 陈青源提壶斟茶，手顿了一下 | 陈青源手提茶壶 | 两人桌边对坐，茶壶在桌上 |
| 姚素素右手一翻取出乾坤袋 | 姚素素右手一翻持乾坤袋 | 姚素素端坐客位，双手自然放置 |
| 陈青源望着灵脉忽然笑了 | 陈青源仰望殿顶盘旋的灵脉 | 陈青源坐空位平视前方 |

判断方法：把"唯一动作"里每个动词遮掉，首帧里就不该出现那个动词带来的状态。

## 5. 对白估时（镜头规则）

- 先排完整声音事件，再定镜长：对白按约 4.5 字/秒估区间，加句间停顿和说完后的反应；边说边做的动作可与对白并行，必须等话说完的动作另占时间
- 动作估时按类型：打斗类动作约 5 秒；移动和肢体动作（移动物品、起身、走近）约 1-2 秒
- 取容得下的最小合法档（5/10/15 秒）；不要先选短档再让人物加快语速
- 超过 15 秒容量 → 按可见状态闭合点拆镜，拆出的每镜各有唯一职责

## 6. 承受者反应（镜头规则）

- 打击、否定、翻盘需要观众理解后果时，必须有可读的反应承载：独立反应镜、双人镜内调度、清楚的群像反应、声音或物件状态
- 现有画面已清楚时不补镜；按「后果能否被读出」判断，不按反应镜数量

## 7. 动作对白合理性（默认手艺）

- 每个分镜中人物的主要动作不超过两个，比如：A 坐下，B 走近 A，就不能再有其他动态动作了。可用静态动作替换
- 动作和对白要符合逻辑，不能出现前后矛盾的动作和对白
- 动作写常见动作的组合与时机；精细编排（运动中截物、三步以上双手动作）图生视频不可用

## 8. 角色对应（硬规则）

- characters 列表列出的角色不得超过 4 个，超过 4 人，用群体称呼替代
- characters 列表与实际出场角色一致
- **编号规则：只有「地点一致 + 角色一致」两个条件同时满足，才用同主号子号递增；地点变化，或角色组发生增减（有人离开/加入），必须开新主号**
- 同主号连续分镜的角色组必须一致；角色增减（离开/加入）必须在 `### 声音` 或 `唯一动作` 中明确交代，不能凭空出现
- 同主号连续分镜的 `角色` position 必须参考同场景上一分镜推导：上一镜 `终点` 里某角色站在哪、朝向哪、持什么，本镜 position 就从那里接续，不能凭空重写；新主号（场景或角色组变化）才按剧本重新设定

## 9. 边界连续（镜头规则）

- 本镜 `终点` 必须与下一镜的起点状态一致；不一致时必须声明过渡或修订，不得用镜头描述掩盖
- 检查分镜之间衔接：地点跳转、时间跳转、话题跳转、角色连续性、位置连贯性

## 10. 道具连续性（镜头规则）

- 跨镜出现的道具（玉镯、信件、令牌等）必须在 `道具` 字段中列出，CLI 通过 `prop_map.yaml` 映射到 assets 目录
- 道具状态变化（易主、拆封、损坏）必须在 `道具` 的 `@状态` 中写明本镜开始时的状态；`终点` 也要反映道具的最终状态
- 道具在 `### 首帧提示词` 中只投影起点可见的状态——终点才出现的道具状态（如"取出的玉镯"）不能写进首帧
- 同一道具的转手、拆封、损坏等动作遵循动作唯一落实（第 3 节）：全章只有一个主要落实镜

## 11. 竖屏景别（默认手艺）

- 竖屏以中景、近景、特写为主；远景/全景要靠纵深分层（前景遮挡、门框、台阶、人物前后）承担交代空间的职责，做不到就改更近的镜头单独给一次
- 景别只在注意或关系变化时改变；不把景别当情绪音量旋钮（情绪词一升级就切大特写是坏味道）
- 关键信息的可读性优先于装饰性运镜；竖屏构图优先保证主体和反应可见
