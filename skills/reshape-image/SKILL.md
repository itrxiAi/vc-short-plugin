# 图片身材重塑

用 OpenCV remap 做液化式几何变形，支持五个维度。**不调用任何 AI/API**，效果可量化、可复现。

## 前置条件

- `vcshort` 通过 pip 安装（`pip install vcshort`），安装后命令会加入 PATH：
  - 任意 shell：`vcshort <command> ...`
- 下文 `vcshort <command>` 均指该命令
- 若命令不存在：请运行 `pip install --upgrade vcshort` 重新安装
- 待修改的资产图片已存在于 `assets/` 目录中

## 输入参数

| 参数 | 说明 | 示例 |
|------|------|------|
| **项目路径** | 项目根目录的绝对路径 | `/Users/.../机甲女王` |
| **资产名称** | assets 目录中的资产名，角色多形态用 `角色名:形态名` | `沈昭蕴:训练服2` |
| **塑形要求** | 用户想要的效果 | `瘦一点腿拉长` / `变矮一点` / `头小一点` |

## 变形参数（缩放系数，1.0 = 不变）

| 选项 | 效果 |
|------|------|
| `--width` | 整体宽窄：<1 变瘦，>1 变胖（肩部以下生效） |
| `--stretch` | 全身横向均匀缩放（含头部）：>1 纯拉宽，<1 纯压窄 |
| `--waist` | 腰部宽窄：<1 收腰，>1 腰粗 |
| `--height` | 身高：>1 变高，<1 变矮（脚底固定） |
| `--legs` | 腿长占比：>1 腿变长（躯干自动缩短），<1 腿变短 |
| `--head` | 头部大小：<1 头小，>1 头大 |

参考幅度：微调 ±0.03~0.06，明显变化 ±0.10~0.15，超过 ±0.2 容易失真。

## 执行步骤

### 1. 收集参数

向用户确认塑形要求，映射为系数。

### 2. 查找资产图片

从 `assets/` 目录按约定查找（与 fix-image 相同规则）：
- 角色多形态：`assets/characters/<角色名>/<角色名>-<形态名>.png`
- 角色默认形态：`assets/characters/<角色名>/<角色名>.png`

### 3. 标注视图语义坐标（必填）

语义位置判据——以手臂为参照物（站立人物手臂自然下垂时最可靠）：

| 字段 | 判据 |
|------|------|
| `neck_y` | **脖子**（下巴/领口下沿，头身分界） |
| `shoulder_y` | **手臂根部**（肩线；缺省=neck_y+0.06×身高） |
| `waist_y` | **手臂中间**（肘部所在高度） |
| `hip_y` | **手腕位置**（胯部/腿根） |

`neck_y` 决定头/躯干分段和 `--head` 缩放范围；`shoulder_y` 决定 `--width` 宽窄变形的起始位置。

标注流程：

1. **裁剪 + 网格**：把每个全身视图单独裁出放大，画上 50~100px 横向网格线（cv2 画线即可），从网格读数——直接看整图目测误差可达 ±100px
2. **先读手臂三个点**：手臂根部（→shoulder_y）、肘部（→waist_y）、手腕（→hip_y）。先定手臂锚点再填字段，不要凭"解剖学腰部"直觉单独估——收腰外套的腰带位置会骗人
3. 对每个全身视图组装 JSON：

```json
[{"x": [0, 680], "cx": 380, "top_y": 75, "bottom_y": 1590,
  "neck_y": 370, "waist_y": 720, "hip_y": 950, "sigma": 0.06}]
```

- **必填**：`x`（视图横向范围）、`neck_y`、`waist_y`、`hip_y`
- **可省略**：`cx`（缺省取 x 中点）、`top_y`/`bottom_y`（缺省取范围内人物最高/最低像素）、`sigma`（腰部高斯宽度/身高比例，缺省 0.10；做局部肚腩用 0.05~0.07）、`torso_x`（腰高处躯干左右边界，限定 `--waist` 凸起只作用于躯干剪影内；不标时凸起会溢出到手臂，内缘位移多于外缘导致手臂视觉变细）
- 面部特写、半身视图不要列入
3. **画标注预览图给用户确认**（颈/腰/胯各画一条彩色横线），确认后再跑变形——标错位置变形就错

### 4. 预览

```bash
vcshort reshape-image <项目路径> \
  --name <资产名> \
  --regions '<JSON>' \
  --width 0.95 --waist 0.88 --legs 1.08
```

默认输出 `<文件名>-reshape.png`，**不改原图**。向用户展示预览。

### 5. 确认后应用

用户满意 → 加 `--inplace` 重跑：原图备份为 `<name>.png.bak` 并覆盖。
不满意 → 调系数重跑预览；放弃则删除 `-reshape.png`。

## 注意事项

- 纯像素变形：白底/纯色底最安全；复杂背景在变形处会被一起拉动，需注意穿帮
- **拉宽（>1）优先用 `--stretch`**：`--width`/`--waist` 在肩部有渐变过渡，拉宽时可能把手臂等细长结构剪断；`--stretch` 全图均匀无剪切
- 收窄（<1）用 `--width`/`--waist` 即可，压缩不会穿帮
- 只处理全身视图；脸部特写面板会被自动跳过（宽高比 ≥0.5）
- `--inplace` 后不满意可从 `.bak` 恢复
